# /cpv-fix-marketplace-validation Command

Reads a marketplace validation report file and fixes the issues it contains, one by one, in priority order. If the report includes any `category: architecture` findings, the agent pauses the mechanical fix path and walks the user through a Layout A / Layout B migration via `migrate-marketplace-architecture`.

## Usage

```
/cpv-fix-marketplace-validation <report_file_path>
```

The argument is optional — if omitted, the marketplace-fixer agent asks what the user would like to do (mechanical fix, architectural migration, or pipeline standardization) via a First Contact menu.

## Arguments

| Argument            | Required | Description                                                                                            |
|---------------------|----------|--------------------------------------------------------------------------------------------------------|
| `report_file_path`  | No       | Path to a marketplace validation report .md or .json file generated by `/cpv-validate-github-marketplace` or equivalent. |

## Workflow

1. The marketplace-fixer agent reads the report file (or asks the user for one).
2. Screens all findings for `category: architecture`. If any are present, hands off to `migrate-marketplace-architecture` BEFORE any mechanical fix. Architectural migrations require extensive `AskUserQuestion` interaction (layout choice, owner, licenses, per-plugin metadata).
3. For remaining mechanical findings, fixes in strict priority order: CRITICAL → MAJOR → MINOR → NIT.
4. Consults `fix-marketplace-validation` to map each error to the correct fix guide section, then applies the Edit.
5. Skips WARNING items (advisory only).
6. Writes a fix log to `$MAIN_ROOT/reports/marketplace-fixer/<YYYYMMDD_HHMMSS±HHMM>-<slug>.md`.
7. Returns a one-line summary: `fixed N of M issues. Report: <filepath>`.

## Examples

```
/cpv-fix-marketplace-validation reports/validate_marketplace/20260421_183012+0200-my-hub.md
/cpv-fix-marketplace-validation reports/validate_marketplace_pipeline/20260421_183012+0200-acme.md
/cpv-fix-marketplace-validation
```

The third form (no argument) triggers the First Contact menu in the marketplace-fixer agent.

## Output

All outputs land at the **main-repo root** (never a linked worktree). Resolve via `git worktree list | head -n1`. Both `reports/` and `reports_dev/` are gitignored.

- Fix log: `$MAIN_ROOT/reports/marketplace-fixer/<YYYYMMDD_HHMMSS±HHMM>-<slug>.md`
- Summary: number of issues fixed vs total
- For architectural migrations: migration log at `$MAIN_ROOT/reports/migrate-marketplace-architecture/<YYYYMMDD_HHMMSS±HHMM>-<slug>.md` recording every user decision and every command run (produced by the `migrate-marketplace-architecture` skill)
