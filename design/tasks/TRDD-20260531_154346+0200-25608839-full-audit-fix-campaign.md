## Gotchas hit (for next time)

- **Server overload throttles big Opus bursts.** A 32-agent Opus burst (and a
  56-agent Sonnet burst) flamed out 0-token with "completed without
  StructuredOutput" / "temporarily limiting". Fix: **waves of 6** + resume
  (`resumeFromRunId` re-runs only the errored batches; the rest return cached).
- **Fix agents bloated 3 agent .md files past CPV's own size limits**
  (description >300 tokens, body >2000 words) — the [[agent-trim-and-release-gotchas]]
  trap. Trimmed by hand post-fix; self-scan back to 0/0/0/0.
- **12 fix-agent test files set `os.environ.setdefault("CPV_SCAN_CACHE","0")`
  at module level** — leaks process-wide at COLLECTION time, disabling the
  cache for the whole serial/xdist run and breaking cache-CONTRACT tests
  (`entries:0`). Fixed by force-enabling (`monkeypatch.delenv("CPV_SCAN_CACHE")`)
  in the two cache-test isolation fixtures. (Residual hygiene debt: the 12
  module-level setdefaults remain — benign now, but should become per-test
  autouse fixtures eventually.)
- **Audit MED #15 (lint return contract):** `lint_markdown/css/html/sql`
  returned False for NIT/MINOR-only, violating the documented "True iff no
  MAJOR/CRITICAL" contract; the existing Issue-#20 tests pinned the violation.
  Fixed the helpers + updated 2 stale tests.
