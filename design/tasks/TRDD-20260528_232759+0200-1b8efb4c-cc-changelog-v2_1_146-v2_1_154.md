### Verification notes

- **#1 MessageDisplay**: official hooks reference (fetched 2026-05-28)
  confirms all 5 hook types and a single `hookSpecificOutput` field
  `displayContent` (string, display-only). It is NOT command-only and
  NOT no-prompt/agent → it stays in **tier 1** (full 5-type set), so NO
  change to `HOOK_EVENTS_COMMAND_ONLY` / `HOOK_EVENTS_NO_PROMPT_OR_AGENT`.
- **#2 SessionStart**: docs confirm `reloadSkills` (boolean) and
  `sessionTitle` (string; applies on `source` startup/resume). `sessionTitle`
  was already present on `UserPromptSubmit` — this adds it to SessionStart.
- **#9 Workflow**: real, user-facing tool (the `/workflows` orchestrator).
  Added with a 2.1.154 comment, mirroring how prior tools were enumerated.

## Security considerations

All additions are allowlist expansions of CC-defined spec surface. No new
exec paths, no relaxation of existing CRITICAL gates. `pluginSuggestionMarketplaces`
/ `allowAllClaudeAiMcps` are managed-only — placing them in project/user
scope must still emit MAJOR (enforced by `MANAGED_ONLY_KEYS` membership).
