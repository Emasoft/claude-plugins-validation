## v2.1.142 backfill — `CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE`

v2.87.0 catalogued v2.1.142 but the env var
`CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE` (added there: *"Set
`CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE=1` to pin fast mode to Opus
4.6"*) was missed when updating `VALID_PLUGIN_ENV_VARS`. Plugin
authors documenting this knob in their READMEs / settings.json `env`
maps currently trip a false-positive unknown-env-var finding. Add it
to `cpv_validation_common.VALID_PLUGIN_ENV_VARS`.

### Change 2 — `skills:` file entry severity demotion

`scripts/validate_plugin.py::validate_skills_field` currently
silently accepts a `skills:` entry that points at a literal
`SKILL.md` file (only emits MAJOR for *non-*`SKILL.md` files).
v2.1.145 says the official `claude plugin validate` now flags
**every** file entry and suggests the parent directory. Mirror:
when `candidate.is_file() and candidate.name == "SKILL.md"`,
emit a **MINOR** with parent-directory hint:

```text
plugin.json::skills[i] = '<path>' points at a file. CC v2.1.145
`claude plugin validate` flags file entries — use the parent
directory '<parent>' instead.
```

Severity rationale: the entry still works at runtime (CC v2.1.142
surfaces a root-level SKILL.md, and the file path likely resolves
the same way), but the official validator now objects. MINOR is
the right tier — flag it, but don't fail validation.

### Change 3 — `context: fork` self-recursion antipattern

`scripts/validate_skill_comprehensive.py` — when a skill has
`context: fork` in its frontmatter, scan its body for `Skill(...)`
invocations whose `skill:` argument resolves to either:

1. The skill's own bare name (e.g. `Skill({skill: "my-skill"})`
   from inside `my-skill/SKILL.md`)
2. The skill's plugin-qualified name (`Skill({skill:
   "<plugin>:my-skill"})`)

If found, emit a **MINOR** with the v2.1.145 changelog reference:

```text
Skill '<name>' has context: fork AND invokes itself via Skill().
CC v2.1.145 fixed an infinite-loop bug where this combination
recursed instead of running. Even with the bug fixed, self-
recursion under a forked context is almost always unintentional
— restructure to call helpers instead.
```

Plugin-qualifier detection: walk up from the SKILL.md to find the
nearest `.claude-plugin/plugin.json` and read its `name:` field.
Fall back to the directory name if the manifest is missing.
