## Changes shipped in v2.84.0

### 1. `terminalSequence` hook output field

`scripts/validate_hook_output.py` — added `terminalSequence` to
`UNIVERSAL_OUTPUT_FIELDS` and added a type check in `validate_output_payload`
that emits MAJOR when the value is not a string (BEL `\\a`, OSC notification
sequences, plain strings — anything Claude Code will write verbatim to the
terminal on behalf of the hook).

Tests: `tests/test_hook_terminal_sequence.py` (8 tests) covering acceptance,
empty-string no-op, BEL, OSC escape, four wrong-type cases, and
co-existence with `continue`/`systemMessage`.

Companion update: `tests/test_validate_hook_output.py::TestConstants::
test_universal_output_fields_exhaustive` extended to include the new field.

### 2. `CLAUDE_CODE_PLUGIN_PREFER_HTTPS` env var

`scripts/cpv_validation_common.py` — added to `VALID_PLUGIN_ENV_VARS`.
Plugin authors will legitimately reference this in setup docs and CI for
HTTPS-only environments without GitHub SSH keys. Tests:
`tests/test_env_vars_v2_1_141.py`.

### 3. `ANTHROPIC_WORKSPACE_ID` env var

`scripts/cpv_validation_common.py` — added to `VALID_PLUGIN_ENV_VARS`.
Used in workload-identity-federation deployments where the federation rule
covers more than one workspace and the minted token must be scoped. Tests:
`tests/test_env_vars_v2_1_141.py`.

### 4. Plugin.json default-folder shadow warning

`scripts/validate_plugin.py` — new check after the existing hooks
duplicate-file detection. When `plugin.json` sets one of `commands`,
`agents`, `skills`, `outputStyles`, the default folder is silently bypassed
at runtime (Claude Code v2.1.140 surfaced this in `/doctor`, `claude plugin
list`, and `/plugin`). CPV emits MAJOR listing each item in the default
folder not reached by the explicit value.

Coverage rules:
- String value pointing at the default folder → covers all (no warning).
- Array containing the bare default folder name → covers all current AND
  future content (no warning).
- Array of file paths where every default-folder item is mentioned → no
  warning.
- Anything else → MAJOR enumerating shadowed entries (capped at 6, plus
  "... and N more" suffix when the shadow list is long).

For `skills` the unit is a subdirectory containing `SKILL.md`, not a flat
file. The same coverage rules apply.

Tests: `tests/test_plugin_json_default_folder_shadow.py` (12 tests)
covering partial coverage, full coverage, bare-folder reference,
string-form coverage, entirely-external arrays, missing default folder,
empty default folder, absent key, plus per-component variants for
`agents`, `outputStyles`, and `skills`.

## Deferred / explicitly not implemented

- **Agent color palette refresh (v2.1.140)** — the changelog does not name
  the new palette colors. CPV's agent-color spec (`red, blue, green,
  yellow, purple, orange, pink, cyan` + hex passthrough) is already
  forward-compatible with any palette refresh that keeps the named-color
  contract.
- **`claude plugin details <name>`** — CPV does not need to mirror this
  command; the projected per-session token cost report is consumer-side.
- **`/goal` overlay panel** — not plugin-validation surface.
- **`/scroll-speed`** — not plugin-validation surface.
- **`terminalSequence` content validation** — CPV does not sniff for
  malformed escape sequences. Authors are responsible for emitting
  well-formed strings; CC writes them verbatim. (If a future release adds
  a deny-list of dangerous sequences, this check can be tightened.)
