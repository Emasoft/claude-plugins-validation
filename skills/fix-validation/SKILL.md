## Overview

Central lookup for the fix agent. Given a validation error, find the reference file with fix instructions. All fix guides are in `agents/references/` and have a TOC in their first 200 chars.

## Prerequisites

- A validation report file generated by `/cpv-validate-plugin` or `/cpv-validate-skill`
- Access to the `agents/references/` directory containing fix guide `.md` files

## Instructions

1. Read the validation report for error messages with severity and file path
2. Match the error to a validator in the index below
3. Open the corresponding fix guide file in `agents/references/`
4. Use the guide's TOC to find the exact section for the error

## Output

The fix agent uses this index to locate the correct fix guide, then applies the fix and logs it to `docs_dev/fix-log_<name>_YYYYMMDD.md`.

## Error Handling

If no matching section is found in the reference file, search by error message keywords. If the reference file is missing, report the gap.

## Examples

Error: `[MAJOR] Missing plugin.json` → Look up validate_plugin.py → Open `agents/references/plugin-structure-fixes.md` → §1. Plugin Manifest Issues.

Error: `[MAJOR] Description too short` → Look up validate_skill_comprehensive.py → Open `agents/references/skill-fixes.md` → §4. Description Quality Issues.
