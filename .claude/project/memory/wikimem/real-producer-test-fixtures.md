# real-producer-test-fixtures


^ATOM-LQ6A-OXYE [desc: "Fixtures must come from the real producer; hand-written ones stay green while the producer's shape moves", keywords: test_fixture_drift hand-written_fixture real_producer_output green_test_wrong_shape integrator_fleet_warning baseline_ruleset_payload_fixture, type: project, ocd: 2026-08-19, lmd: 2026-08-19]

Test fixtures for a producer/consumer seam MUST be generated by the REAL producer, not hand-written. During TRDD-QOZXF6A6 (ratified baseline trio payloads) the integrator fleet warned that hand-authored ruleset-payload fixtures had drifted from what the janitor's branch_protection_lib actually emits — tests stayed green against a shape the producer no longer produces. The fix pattern: the test suite invokes the producer (or a checked-in snapshot regenerated by CI from the producer) to build the fixture, so a producer change breaks the consumer test instead of silently bypassing it.
